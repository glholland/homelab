# media

Jellyfin (streaming), Jellyseerr (requests), Prowlarr (indexers),
Radarr/Sonarr (PVRs), SABnzbd (downloader), plus `backlog-search` and
`recyclarr` CronJobs.

## Layout

| File | Contents |
| :--- | :--- |
| `namespace.yaml` | the `media` namespace |
| `rbac.yaml` | `media-apps` ServiceAccount + `anyuid` SCC binding (linuxserver.io images run as PUID/PGID 1000) |
| `pv-media-shared.yaml` | static NFS PVs for the shared libraries — must exist before the claims bind |
| `pvcs.yaml` | per-app config PVCs on `truenas-nfs-retain`, plus the three static-PV claims |
| `secrets.yaml` | `recyclarr-api-keys` (AVP references) |
| `configmaps.yaml` | `backlog-search-script`, `recyclarr-config` |
| `<app>.yaml` | one per app: Deployment, Service, Ingress, Certificate |
| `cronjobs.yaml` | `backlog-search` (*/15), `recyclarr` (weekly) |

## Ingress, not Route

Routes are generated by OKD from these `Ingress` objects. A hand-written Route
cannot reference a TLS Secret, so it would require the certificate and private
key inline in the manifest.

## Secret Manager

Project `home-26300` (`812524172865`): `radarr-api-key`, `sonarr-api-key`.
Both are consumed through the `recyclarr-api-keys` Secret. The `*-tls` Secrets
are issued by cert-manager and need no entries.
